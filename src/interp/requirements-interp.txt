#
#   python -m venv .venv && source .venv/bin/activate
#   pip install -r src/interp/requirements-interp.txt
#
# GPU box: install the CUDA build of torch FIRST, from https://pytorch.org/get-started/,
#   e.g.  pip install torch --index-url https://download.pytorch.org/whl/cu124
# then run this file (pip will keep the already-installed torch). CPU-only also works —
# CLIP (Component 1) just runs on CPU. Only Component 1 needs torch/transformers; the
# other studies use numpy/scipy/sklearn/matplotlib and degrade gracefully without CLIP.
#
# NOTE: the repo's mac dev box pins torch==2.2.2 / transformers==4.49 / numpy<2 (Intel
# macOS has no newer torch wheel) — those pins are NOT needed on Linux; modern versions
# below resolve cleanly.
